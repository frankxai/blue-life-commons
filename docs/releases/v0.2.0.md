# Blue Life Commons v0.2.0 release candidate

This candidate blesses the 27 commits after `v0.1.0` through production commit
`8c78ce83b83696e565900c71289f9c7e31e85767` (2026-08-10). It remains a draft:
no `v0.2.0` tag or GitHub release has been created.

## What changed

- Launched the public Blue Life Commons experience across the encyclopedia,
  regions, missions, research, Guardian, catalog, impact, governance, privacy,
  contribution, support, services, and ecosystem surfaces.
- Expanded the species experience with approved source media, licensed proof,
  resilient storage, and a full Blue Whale page.
- Added a 13-entry Deep Time marine-reptile collection with explicit concept-
  reconstruction disclosures, scale context, imagery, and video coverage.
- Added media-intelligence operations, Blob mirroring, cost/ROI documentation,
  and media-policy enforcement.
- Added public-truth, privacy, review-state, built-output, link, and visual-work
  gates so the live site cannot quietly outrun its evidence.

## Honest limits

- `/changelog` is not yet a public site route. The repository changelog is the
  current source of truth.
- The site still exposes content-specific review states. This release records
  the product and governance work; it does not promote scientific artifacts.
- The private application's `package.json` version is not an npm publication or
  evidence that a `v1.0.0` repository release exists.
- Publishing the GitHub release and any production promotion remain explicit
  human decisions.
